# Личная библиотека (Вариант 1)

**Тема:** Личная библиотека  
**Вариант:** 1  
**ФИО:** Елизовета Акулова  
**Группа:** ИСиП1-9-24

Учебный проект на FastAPI. Представляет собой веб-приложение, где пользователь может вести свой личный каталог книг. Реализована регистрация и авторизация, добавление книг с указанием жанра, статуса чтения и оценки, а также фильтрация и поиск по каталогу.

## Функционал

- Регистрация, вход и выход из системы (сессии на основе cookie).
- Просмотр, добавление, редактирование и удаление только своих книг.
- Справочники жанров, издательств и личных полок.
- Указание статуса книги: «Хочу прочитать», «Читаю», «Прочитано».
- Выставление личной оценки от 1 до 5.
- Поиск по названию книги или автору.
- Фильтрация по статусу, жанру, издательству и полке.
- Сортировка (по дате добавления, названию, оценке).
- Статистика по жанрам (количество книг в каждом жанре).
- Адаптивный интерфейс (не разваливается на мобильных экранах от 360 px).

## Технологии

- **Бэкенд:** Python, FastAPI, APIRouter, Pydantic (схемы Create, Update, Out).
- **База данных:** SQLite, SQLAlchemy 2.0 (модели `Mapped`, `mapped_column`, запросы `select`).
- **Миграции:** Alembic (все таблицы создаются только через миграции).
- **Авторизация:** `SessionMiddleware` (user_id хранится в подписанной cookie). Пароли хешируются с солью (Argon2 через `pwdlib`).
- **Фронтенд:** Чистый HTML5, CSS3, JavaScript (ES6+). Запросы через `fetch` API. Без фреймворков.
